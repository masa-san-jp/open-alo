# Open ALO Studio

Studio is a dependency-free local web UI for writing, validating, visualizing,
and running ALO documents. Launch it from the repository with:

```bash
alo studio
```

The default bind address is `127.0.0.1`. Use `--port 0` (the default) to let
the operating system choose a free port, or pass `--no-browser` when the
browser should not open automatically.

## API

All request bodies are JSON objects. Malformed bodies return HTTP 400 with
`{"errors": ["..."]}`. ALO parse and validation failures return HTTP 200 with
the same error-only shape, except `/api/validate`, which always returns its
`valid` and `errors` fields.

`GET /api/examples`

Returns an array containing the bundled example files:

```json
[
  {"id": "minimal", "path": "examples/minimal/alo.yaml", "source": "..."}
]
```

`POST /api/validate`

Request: `{"source": "<YAML or JSON text>"}`

Response: `{"valid": true, "errors": []}` or
`{"valid": false, "errors": ["..."]}`.

`POST /api/graph`

Request: `{"source": "<YAML or JSON text>", "direction": "TD"}`;
`direction` is optional and supports the Mermaid directions `TB`, `TD`, `BT`,
`LR`, and `RL`.

Success response:

```json
{"graph": {"graph_ir_version": "0.1", "source": {}, "nodes": [], "edges": []}, "mermaid": "...", "svg": "<svg ...>...</svg>"}
```

`POST /api/run`

Request: `{"source": "<YAML or JSON text>", "input": {}, "responses": {}}`.
Both object fields default to `{}`. Success returns the Run Record JSON
directly. `/api/run` uses only `MockDecisionProvider` today by design: the
no-login local mode works without a network connection or API key.

The Studio's import file control uses the browser `FileReader` API, and its
Download button uses a client-side `Blob`; neither operation writes to the
server filesystem. The graph viewer uses the SVG generated by Python and has
no external JavaScript, framework, stylesheet, or CDN dependency.
