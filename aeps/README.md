# ALO Enhancement Proposals

This directory holds AEPs: proposals for substantial changes to the Open ALO
specification, Graph IR, Run Record format, or Decision Provider interface.

See [`docs/aep-process.md`](../docs/aep-process.md) for when an AEP is
required, the proposal format, and the decision process. Start a new
proposal from [`0000-template.md`](0000-template.md).

No AEPs have been accepted yet — the process itself was only just defined.
